🎵 SongApp - Cambia Tonalità e Ascolta le Tue Canzoni Preferite
SongApp è un'applicazione mobile sviluppata con React Native, Firebase e MySQL che ti permette di suonare e ascoltare le tue canzoni preferite con funzionalità avanzate per musicisti.

✨ Funzionalità principali
🎸 Cambia tonalità – Modifica la tonalità delle canzoni per adattarle al tuo strumento musicale.
🎹 Adattamento automatico – Seleziona il tuo strumento e gli accordi verranno aggiornati di conseguenza.
🎧 Ascolta la musica – Riproduci le canzoni direttamente dall’app.
📀 Playlist personalizzate – Crea e gestisci playlist, come su una piattaforma tipo Spotify.

🛠️ Tecnologie utilizzate
React Native – Per lo sviluppo dell'app mobile.
Firebase – Per autenticazione e database in tempo reale.
MySQL – Per la gestione dei dati delle canzoni e utenti.
